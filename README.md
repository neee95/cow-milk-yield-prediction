# Прогнозирование удоя и вкуса молока с помощью линейных моделей

## О проекте

Проект решает две задачи для фермерского хозяйства:
1. **Регрессия** — прогноз годового удоя коровы (`milk_yield`) для отбора перспективных коров.
2. **Классификация** — прогноз вкуса молока (`milk_taste`) для минимизации рисков при покупке.

## Данные

Три CSV-файла (разделитель `;`) в папке `data/`:
- `ferma_main.csv` — основная информация о коровах (порода, возраст, показатели корма, целевые признаки)
- `ferma_dad.csv` — имена пап коров, связь по `id`
- `cow_buy.csv` — коровы для покупки, для которых нужен прогноз

## Шаг 5. Задача регрессии

**Целевой признак:** `milk_yield`.

**Построены три модели линейной регрессии:**

| Модель | Особенности | R² | MSE | MAE | RMSE |
|--------|-------------|-----|-----|------|------|
| 1 | Базовые признаки | 0.784 | 43887 | 164.2 | 209.5 |
| 2 | + `spr_binary`, `square_feed_energy` | 0.818 | 37031 | 149.0 | 192.4 |
| 3 | + логарифмирование `y` (`np.log1p`) | **0.825** | **35549** | **145.5** | **188.5** |

**Лучшая модель — третья.** Объясняет 82.5 % дисперсии удоя.

**Анализ остатков:**
- Наблюдается **гетероскедастичность** — дисперсия остатков растет с увеличением прогноза.
- Распределение остатков смещено влево — модель немного переоценивает целевой признак.

**Доверительный интервал модели:** 6097.83 – 6223.3.

**Прогноз для `cow_buy.csv`:**
- Данных о кормлении нет → использованы средние по ферме значения кормовых признаков с надбавкой +5%.
- Прогнозы удоя: **6040–6545 кг/год**, все коровы превышают порог 6000 кг.
- Прогнозы различаются только по породе, пастбищу, породе папы и возрасту.

## Шаг 6. Задача классификации

**Целевой признак:** `milk_taste` (1 — вкусно, 0 — не вкусно).

Распределение классов: **370 "вкусно" / 258 "не вкусно"**.

**Модель:** логистическая регрессия. Признаки: `breed`, `pasture_type`, `dads_breed`, `age`, `spr_binary`, `square_feed_energy`, `crude_protein`, `fat_content`, `protein`, `milk_yield`.

**Результаты при стандартном пороге 0.5:**
- Accuracy: **0.637**
- Recall: **0.864**
- Precision: **0.628**
- Матрица ошибок: **45 FP** (ошибка I рода), **12 FN** (ошибка II рода)

**Критичная ошибка** — I рода (FP): модель говорит «вкусно», а молоко невкусное. Это прямой риск убытков.

**Оптимизация порога для FP = 0:**
- Порог поднят до **0.79**:
  - Precision = **1.0**
  - Recall = **0.125**
  - Accuracy = **0.510**
  - TP = 11, FP = 0, FN = 77, TN = 69

**Прогноз для `cow_buy.csv`:**
- Максимальная вероятность «вкусно» = **0.743** — **ниже** порога 0.79.
- Следовательно, при строгом пороге **ни одна корова не проходит отбор**.

## Шаг 7. Итоговые выводы

### Сколько коров фермер может купить с минимальным риском?

**Ответ: 0 коров** при строгом пороге 0.79.

Причина: максимальная вероятность «вкусно» для коров из `cow_buy.csv` = 0.743 — ниже порога.

**Компромисс:** снизить порог до **0.5–0.6** — часть коров пройдёт отбор, но появится риск купить невкусную.

### Рекомендации фермеру

1. **Собрать данные о кормлении** для `cow_buy.csv` — ключевой признак для прогноза.
2. **Использовать компромиссный порог** (0.6–0.7) для классификации вкуса.
3. **Провести дополнительный осмотр** отобранных коров.
4. **Рассмотреть покупку коров с высоким удоем** при неопределённом вкусе, если молоко пойдёт на переработку.
5. **Расширить выборку** — 20 коров слишком мало для надёжного отбора.

### Выводы о моделях

**Регрессия:**
- R² = 0.825, MAE = 145.5 кг, RMSE = 188.5 кг.
- Основные признаки: ЭКЕ², сырой протеин, порода, тип пастбища, возраст.
- Есть гетероскедастичность.

**Классификация:**
- Чувствительна к порогу → позволяет управлять балансом FP / Recall.
- Порог 0.5: хороший Recall, но высокий риск FP.
- Порог 0.79: нулевой FP, но почти нулевой Recall.

### Способы улучшения регрессионной модели

**Уже применены:**
1. Логарифмирование целевого признака (`np.log1p`)
2. Полиномиальный признак `square_feed_energy = ЭКЕ²`
3. Бинаризация СПО по порогу 0.91
4. `StandardScaler` для количественных признаков
5. `OneHotEncoder` для категориальных

**Возможные улучшения:**
1. Добавить признаки: здоровье, количество отелов, сезон, условия содержания.
2. Нелинейные модели: Random Forest, Gradient Boosting, нейронные сети.
3. Регуляризация: Lasso, Ridge, ElasticNet.
4. Кросс-валидация для подбора гиперпараметров.
5. Собрать данные о кормлении для `cow_buy.csv`.

### Метрики классификации для анализа рисков

1. **Precision** — критична при экономических расчётах: доля верных предсказаний «вкусно». Высокий Precision = низкий риск.
2. **Recall** — важна, если цель найти как можно больше вкусных коров.
3. **F1-мера** — баланс Precision и Recall.
4. **ROC-AUC** — качество модели независимо от порога.
5. **Precision-Recall AUC** — полезна при дисбалансе классов.

**Итог:** для минимизации рисков важнее **Precision**, для максимизации количества найденных вкусных коров — **Recall**. В задаче выбран компромисс через порог: 0.79 даёт Precision = 1.0, но Recall = 0.125.
